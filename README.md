# Sharp bounds for paired discrimination

This repository contains the Python implementation accompanying “Sharp bounds for paired comparisons of discrimination under arbitrary label nonresponse.” It implements the finite-cohort and population bounds and provides code to reproduce the simulation design.

## Requirements

Python 3.11 (`>=3.11,<3.12`).

## Installation

```bash
python -m venv .venv
python -m pip install -r requirements.txt
python -m pip install -e .
```

Activate the virtual environment using the command appropriate for your shell before installing dependencies.

## Run tests

```bash
pytest -q
```

## Run the simulation

```bash
python scripts/calibrate_verification.py
python scripts/run_simulation.py --workers 8
```

The first command writes calibrated verification intercepts under `results/calibration/`. The second command reads those intercepts and writes simulation outputs under `results/simulation/`. Outputs are generated locally and are not stored in this repository.

## Repository structure

- `src/`: bounds, population formulas, calibration, and simulation implementation.
- `scripts/`: calibration and simulation entry points.
- `config/`: reproducible simulation specification.
- `tests/`: direct unit tests, including small-sample exhaustive checks.

## Data

No external dataset is used. All data analyzed in the manuscript are simulated and can be generated by the code in this repository.
